# 用語集

本プロジェクトにおいて、ドメインの概念を正確に表現するため、空間や時間に関する用語を以下の通り定義し、使い分けています。

過去の設計において「セル (Cell)」という用語が複数の意味（時間の単位、木構造のノード、空間の範囲など）で乱用され混乱を招いていたため、現在のコードベースではドメイン用語としての「セル」の使用を全面的に廃止し、以下の4つに厳格に区別しています。

## 1. Interval

- **定義**: 時間軸の解像度（時間単位 `i`）を表す値。
- **コード例**: `Interval` 型

## 2. TimeSpan

- **定義**: 1次元の数直線上における任意の連続した範囲 `[start, end)`。
- **特徴**: 開始値と終了値によって定義され、長さに制約はありません。木構造の境界に揃っている必要もありません。日本語では区間と呼ぶ。
- **使用例**: 「任意の時間区間」

## 3. TimeSegment

- **定義**: 1次元の数直線上において、2分岐（Segment木など）によって再帰的に分割されたブロックの1つ。
- **特徴**: 常に「2の冪乗」の長さを持ち、特定の境界にアライメントされている必要があります。任意の「区間 (TimeSpan)」を木構造に格納する場合、1つ以上の「TimeSegment」に分解して扱います。
- **使用例**: 「時間Segment (Temporal TimeSegment) へ分解する」
- **コード例**: `TimeSegments` 型

## 4. FlexId

- **定義**: 複数の次元（F, X, Y, 時間など）において、それぞれが「TimeSegment」として分割された結果組み合わさってできる、多次元の空間的・時間的な範囲。
- **コード例**: `FlexId`

---

## 「セル」を使わない

上のとおり「セル」はドメイン用語として廃止しています。散文でも識別子でも使いません。
このリポジトリで「セル」と呼ばれていたものは、ほぼすべて **`FlexId`**（格納された 1 件の
`(FlexId, 値)`、あるいは 1 つの多次元範囲）を指していました。

```text
1 リーフが最大 1024 セル      ->  1 リーフが最大 1024 FlexId
全セルが読み戻せること        ->  全 FlexId が読み戻せること
fn insert_cells(...)          ->  fn insert_flex_ids(...)
read_cells_in_range(...)      ->  read_flex_ids_in_range(...)
```

**「ボクセル」は別語**なので置き換えの対象外です（`docs/spatial-id.md` を参照）。
空間 ID が指す直方体そのものを説明する文脈で使われています。
