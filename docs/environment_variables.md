# 環境変数 (Environment Variables)

Kasaneでは、設定を環境変数で変更することができます。また、`.env` ファイルをプロジェクトルートに配置することで、環境変数を自動的に読み込みます。

以下は、利用可能なすべての環境変数のリストとその説明です。

## アプリケーション設定

| 変数名 | デフォルト値 | 説明 |
| :--- | :--- | :--- |
| `FILE` | `default.kasane` | データベースファイルのパスを指定します。コマンドライン引数 `--database-path` が指定されていない場合、この環境変数が使用されます。 |
| `PORT` | `5173` | サーバーがリッスンするポート番号を指定します。コマンドライン引数 `--port` が指定されていない場合、この環境変数が使用されます。|
| `LOG_MODE` | `kasane=info,tower_http=info` | ログの出力レベルを指定します。`tracing_subscriber::EnvFilter` の書式に従います。 |
| `ROOT_PASSWORD` | `password` | データベース初期化時に自動作成されるrootのパスワードです。 |
| `JWT_SECRET` | （未設定時はプロセスごとにランダム生成） | JWTトークンの署名・検証に使用されるシークレットキーです。未設定または空の場合、起動時に暗号論的乱数で一時的な鍵を生成します（既知の固定鍵によるトークン偽造を防ぐため）。この一時鍵は**再起動のたびに変わり、発行済みトークンはすべて無効化されます**。**本番環境では必ず安全でユニークな文字列を明示的に設定してください。** |
