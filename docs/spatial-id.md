# 空間ID・時空間ID 仕様まとめ

## 1. 空間ID (Spatial ID)

3次元空間を直方格子状に分割した直方体（空間ボクセル）に割り当てられる、一意の識別子です 。

### 1.1 フォーマット

基本フォーマットは以下の通りです 。

* **`{z}/{f}/{x}/{y}`**
  * `z`: ズームレベル 
  * `f`: 標高（鉛直方向）インデックス 
  * `x`: 経度（東西方向）インデックス 
  * `y`: 緯度（南北方向）インデックス 

### 1.2 空間の基準

*  **高さの基準**: ジオイド（標高0m）を基準面とします 。
*  **水平方向の範囲**: Webメルカトル図法の範囲（経度: 西経180度〜東経180度、緯度: 南緯85.0511度〜北緯85.0511度）をズームレベル0の全体範囲とします 。
* **鉛直方向の範囲**: ズームレベル0において、プラス方向は標高0m〜33,554,432m、マイナス方向は0m〜-33,554,432mとします 。

### 1.3 インデックス算出用の計算式

経度、緯度、標高、ズームレベルから各インデックス（f, x, y）を算出する計算式は以下の通りです 。

**【変数定義】**

* $lng$: 経度 [10進度] 
* $lat\_rad$: 緯度 [ラジアン] 
* $h$: 標高 [m] 
* $z$: ズームレベル 
* $n = 2^z$ 
* $Z = 25$（ボクセルの高さが1mとなるズームレベル） 
* $H = 2^Z$ [m] 

**【計算式】**

* $f = floor(n * \frac{h}{H})$ 
* $x = floor(n * (\frac{lng + 180}{360}))$ 
* $y = floor(\frac{n}{2} * (1 - \frac{log(tan(lat\_rad) + \frac{1}{cos(lat\_rad)})}{\pi}))$ 

## 2. 時空間ID (Spatio-Temporal ID)

空間IDに「時間ID（時間間隔と時間インデックス）」を付加し、時間に応じて変化や移動する情報を扱うための識別子です 。

### 2.1 フォーマット

フォーマットは以下の通りです 。

* **`{z}/{f}/{x}/{y}_{i}/{t}`**
* 2次元の空間ID（`{z}/{x}/{y}`）を使用した際との混同を避けるため、空間IDと時間IDの連結文字にはアンダースコア（`_`）を使用します 。

* `{z}/{f}/{x}/{y}`: 空間ID 
* `i`: 時間間隔（秒） 
* `t`: 時間インデックス 

### 2.2 時間の基準
* **時間軸の起点**: 1970年1月1日 0:00（協定世界時: UTC）。UNIX時間の起点を採用しています 。
* **時間間隔 (`i`)**: ユースケースに応じて任意の秒数を指定可能です 。

### 2.3 時間インデックス算出用の計算式

UNIX時間と時間間隔から時間インデックスを算出する計算式は以下の通りです 。

**【変数定義】**
* $u$: UNIX時間（1970年1月1日0:00からの経過秒） 
* $i$: 時間間隔（秒） 

**【計算式】**
* $t = floor(u / i)$ 

### 2.4 時間IDからの秒単位範囲の逆算
時間IDの要素を用いて、該当する秒単位の時間範囲を求めることができます 。
* **時間範囲の始点（秒）**: $i * t$ 
* **時間範囲の終点（秒）**: $(i * t) + i$
